نشاط المحقق العلمي — نسخة رابط للطلاب + تقرير المعلم
====================================================

محتويات المجلد:
1) index.html       : صفحة النشاط التي يفتحها الطلاب.
2) teacher.html     : لوحة تقرير أداء الطلاب.
3) Code.gs          : كود Google Apps Script الذي يحفظ النتائج في Google Sheets.
4) links.html       : أداة لتكوين رابط الطلاب ورابط تقرير المعلم.

رمز تقرير المعلم الحالي:
EM9PRKAHGZI8
احتفظ به ولا ترسله للطلاب.

أولاً: إعداد تجميع النتائج في Google Sheets
-------------------------------------------
1. أنشئ جدول Google Sheets جديدًا باسم مناسب مثل: نتائج المحقق العلمي.
2. من الجدول اختر: الإضافات/Extensions > Apps Script.
3. احذف الكود الموجود والصق محتوى ملف Code.gs كاملًا ثم احفظ.
4. اختر Deploy > New deployment > Web app.
5. Execute as: Me.
6. Who has access: Anyone.
7. انشر التطبيق وانسخ رابط Web App الذي ينتهي بـ /exec.

ثانيًا: نشر النشاط كرابط
-------------------------
ارفع الملفات index.html و teacher.html و links.html إلى مستودع GitHub، ثم فعّل GitHub Pages للمستودع.
بعد ظهور رابط GitHub Pages افتح links.html، وأدخل:
- رابط GitHub Pages.
- رابط Apps Script Web App.
سيولد لك رابطين:
- رابط الطلاب: تشاركه مع الطلاب.
- رابط تقرير المعلم: تحتفظ به لديك.

طريقة عمل الطالب
----------------
- يكتب اسمه.
- يختار فصله من 1/1 أو 2/1 أو 3/1 أو 4/1.
- يحل القضايا الخمس.
- يحفظ تقدمه تلقائيًا على جهازه أثناء الحل.
- عند الإنهاء تُحسب الدرجة من 50 والنسبة ومستوى الحل، ثم تُرسل النتيجة إلى Google Sheets.

تصنيف مستوى الحل
----------------
90–100% : ممتاز
80–89%  : جيد جدًا
70–79%  : جيد
60–69%  : مقبول
أقل من 60%: يحتاج دعمًا

تقرير المعلم
------------
teacher.html يعرض:
- اسم كل طالب وفصله.
- الدرجة من 50 والنسبة.
- مستوى الحل.
- درجة كل قضية من القضايا الخمس.
- زمن الحل.
- تفاصيل كل إجابة صحيحة/غير صحيحة.
- البحث باسم الطالب والتصفية حسب الفصل.
- خيار أحدث محاولة لكل طالب.
- تصدير CSV والطباعة.

ملاحظة مهمة:
لا يمكن لصفحة HTML ثابتة وحدها جمع نتائج الطلاب من أجهزة مختلفة. لذلك تم ربط التصميم بخادم Google Apps Script بسيط يكتب النتائج في Google Sheets. بعد إعداد الخطوات أعلاه يصبح لديك رابط نشاط حقيقي وتقرير مركزي لكل من شارك.
